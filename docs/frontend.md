# 前端界面

服务端编译时会把 `web/dist` 通过 `go embed` 嵌入二进制。

## 当前界面包含

- 登录页
- 管理首页
- 记忆浏览页（标签 + 描述搜索）
- 清理治理页
- 用户管理页
- 保护标签管理
- 待清理审核列表与批量执行
- JWT 路由守卫
- 用户新增、编辑、删除、重置 API Token

## 清理治理页

- 保护标签列表以数据库为准，支持管理员在线新增、编辑、删除
- 支持手动触发一轮清理候选生成，查看评分原因、项目和使用次数
- 执行按钮只会处理当前勾选且状态为“已批准”的候选，避免误删未确认记录

## 记忆浏览页搜索

- 搜索表单拆分为“标签”和“描述”两个输入
- `描述` 为必填，直接对应后端搜索接口的 `description`
- `标签` 为可选，会按空白或逗号拆分后作为 `tags` 发送
- 管理页列表接口在带 `description` 时进入搜索模式，并返回命中置信度

## 构建注意事项

如果直接运行 `go test ./...` 或构建服务端，而 `web/dist` 尚未生成，`go embed` 会因为找不到静态资源而失败。先执行：

```bash
make build-ui
```

或完整构建：

```bash
make build
```
